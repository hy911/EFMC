# 产品规格参数问卷

用途：官网 11 个产品的「规格参数」字段需要真实数据。阿里发品模板里那份是同一套默认值复制到全部产品（型号统一 `EFMC-0816`、尺寸统一 `2200*600*800`、毛重统一 `300KG`），不能直接用。

**怎么填**：直接在本文件里改，每个产品填能填的、填不了的留空或写「不适用」。留空的参数不会出现在网站上，不影响发布。

**填多少合适**：每个产品 5–8 条即可。工业采购方最看重的是**能不能对上他们的工况**，不是参数越多越好。
