# 官网案例交付规范

> **这份是给你看的操作说明，六步走。** 同一文件夹里的 `02-字段规范.md` 是给 AI 助手看的，你不用读。

---

## 六步走

### 第 1 步：新开一个 Codex 对话

**不要**在之前做网页的那个对话里继续——它会顺着老思路又给你做一个网站。开个新的。

### 第 2 步：把整个文件夹交给 Codex

我发你的压缩包解开后是一个文件夹，里面已经备齐了它要的东西：

| 文件 | 是什么 |
| --- | --- |
| `01-先读我.md` | 就是这份，你的操作说明 |
| `02-字段规范.md` | **最重要的一份**，整份给 AI，别删减——每个字段怎么写、有哪些版式可选，末尾还有一段现成的提示词 |
| `example-case.json` | 一份写好的真实案例，告诉它「照这个格式写」（这份只是格式参考，直接拿它跑校验会报「图片缺失」，正常） |
| `case-schema.mjs` | 校验工具，告诉它「写完自己跑这个检查」 |
| `case-preview.mjs` | 预览工具，生成跟官网一模一样的页面让你看 |
| `preview/` | 预览工具要用的渲染器和样式，别删也别改 |
| `case-blocks.json` | 版式清单，上面两个工具都要用，别删也别改 |
| `assets/` | 空文件夹，把你的照片放进去 |

**在 Codex 里打开这个文件夹**（把文件夹拖进去，或者用「打开目录」），然后把 `02-字段规范.md` 最后一节《给 AI 助手的提示词》整段复制给它。

先把现场照片放进 `assets/` 文件夹，技术资料、项目背景介绍一并发给它。

### 第 3 步：它会先问你一串问题，照实回答

它读完规范后**不会直接开写，会先问你缺什么**——这个项目解决了什么问题、改造前后差在哪、有没有实测数据、数据是怎么测的、哪些环节有照片。

**没有的就说没有，不要为了让它写得满而含糊带过。** 这一步是整个流程里最值钱的：你答得准，它就不用编。

### 第 4 步：让 Codex 自己检查

让它跑这条命令，**改到显示「校验通过」为止**：

```bash
node case-schema.mjs case.json
```

这一步很重要。工具会把缺字段、图片名对不上、中文没写完这些问题一次列全，Codex 自己就能改。省掉的是「发给我 → 我导入 → 报错 → 再发回去改」这一轮来回。

### 第 5 步：自己看效果，改到满意

```bash
node case-preview.mjs case.json
```

在同一个文件夹生成 `preview-en.html` 和 `preview-zh.html`，双击用浏览器打开（页面顶上有链接互相切换）。

**这就是它上线之后的样子。** 用的是官网真实的页面组件和样式，排版、字号、留白、配色跟线上一致，不是示意图。

三处跟线上不同，看的时候心里有数就行：

- 页面上下没有导航栏和页脚
- 图片是原图直接显示，线上会自动压缩，实际加载更快
- 没有滚动淡入动画，静态页里一律直接可见

**改一轮就重跑一次这条命令**，刷新浏览器就能看到新的。这一步可以反复做多少轮都行，**不用等我**。定稿了再发我。

### 第 6 步：打包发我，我先导成草稿

把 `case.json` 和 `assets` 文件夹压缩发微信。

**我导成草稿后会给你一条预览链接**，那个页面顶上有红色「草稿预览」条，说明还没上线、外人搜不到也看不到。你和客户看完觉得没问题，我再点发布。

这样改几轮都行，不用担心半成品被人看见。

## 三个最容易出错的地方

**① 别让它做网页。** 官网的案例页版式已经做好了——编号章节、字号、留白、深浅底交替、手机端适配，全都统一。它另做一套的话风格对不上，内容还得逐段拆出来重录，等于白做。它只产出内容，排版交给官网。

**② 数字必须有出处。** 识别率、响应时间这些，只写你手上材料里确实有的。海外客户看到百分比会追着要测试报告，**报告拿不出来比不写更伤**。没有证书的认证、代理授权同理，一律别写。

**③ 图片里不要有文字。** 图上烧死的字翻译不了、搜索引擎读不到、手机上还会糊。所有文字都写进 `case.json`，图只放画面。视频同理——片头片尾不要加字幕板和 logo 动画。

## 关于视频

案例里可以放一段视频，跟照片一样丢进 `assets/` 就行。三条限制：

- **只收 `.mp4`**。手机拍的 `.mov` 先转一下
- **一段就够，30 MB / 1 分钟以内**。视频从我们自己的服务器发，不走视频平台，太大用户等不起
- 页面上是**点击才播、不自动出声**

Codex 会自己从视频里截一帧当封面。

## 关于版式：不用你操心，但有一点要知道

官网的案例页有十来种版式选项（深蓝底、数据卡、彩色状态流、示意图……）。**这些 Codex 会照 `02-字段规范.md` 自己挑**，你不用管。

你只需要在给素材时把话说清楚：**哪几段是测出来的数据、哪几段是流程、哪几段是系统构成**。分类说清楚了，它挑的版式就八九不离十。

有一件事值得你留意：**"没有实物可拍的环节不要硬凑照片"**。比如「AI 识别」「数据上送云端」这种步骤，塞一张机柜照片会让人以为这一步发生在那台设备上。官网能自动画示意图，规范里写了怎么用。
