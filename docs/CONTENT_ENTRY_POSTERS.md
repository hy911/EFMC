# 海报内容录入清单

把阿里国际站 3 张海报（COMPANY ADVANTAGE、团队、COMPANY PROFILE）的内容录进后台。
照着复制粘贴即可，**每个字段都要切英文（EN）和中文（ZH）各填一遍**。

> 电控柜那张（供应商 logo 墙 + 8 张实拍）需要图片素材，不在本清单内，素材齐了再录。
>
> 录入位置：**生产后台**（本地 `/admin` 录的内容不会同步到生产，两个独立数据库）。
